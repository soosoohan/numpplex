넘플X

숫자카드와 연산기호 카드로 수식을 만드세요.

넘플 X (NUMZZLE X)=넘버(NUMBER) + 사과(APPLE)+X

넘플은 수학 감각과 창의력을 발휘해야 하는 재미있는 계산 게임입니다.

📋 게임 규칙

  • 두 사용자는 서로 다른 숫자카드와 연산카드를 받습니다.
  • 두 사용자는 주어진 카드를 모두 사용해야 합니다.
  • 주어진 카드로 수식을 만들어 최대값을 만드는 게임은 넘플초 맥시, ,넘플잼 맥시, 넘플 맥시가 있습니다.
  • 주어진 카드로 수식을 만들어 최소값을 만드는 게임은 넘플초 미니, ,넘플잼 미니, 넘플 미니가 있습니다.
  • 실수했을 경우 초기화 버튼으로 수식을 다시 만들 수 있습니다.
  • 수식의 결과는 각 라운드의 점수가 됩니다.
  • 10라운드가 끝난 후, 맥스 게임은 합계가 크면 이깁니다.
  • 10라운드가 끝난 후, 미니 게임은 합계가 작으면 이깁니다.
  • 게임하는 동안 계산 능력이 향상됩니다.
  • 넘플초는 덧셈(+)과 뺄셈(-) 연산만 사용하며 넘플초보다 쉽습니다.초등학교 2학년 이상이면 게임할 수 있습니다.
  • 넘플잼은 덧셈(+), 뺄셈(-), 곱셈(x) 연산을 사용합니다. 초등학교 3학년 이상이면 게임할 수 있습니다.
  • 넘플은 덧셈(+), 뺄셈(-), 곱셈(x), 나눗셈(÷)을 사용합니다.초등학교 4학년 이상이면 게임할 수 있지만 사고력이 필요한 게임입니다.

NUMPPLEX

Create expressions with given cards.

NUMPPLE X = NUMBER + APPLE +X

Numpple X is a fun and strategic math game that challenges your sense of numbers and creativity.

📋 Game Rules

  • Two users receive different number cards and operation cards.
  • Two users must use all given cards.
  • Games where you create expressions with given cards to make the maximum value are Number Cho X Maxi, Number Jam X Maxi, and Number X Maxi.
  • Games where you create expressions with given cards to make the minimum value are Number Cho X Mini, Number Jam X Mini, and Number X Mini.
  • If you make a mistake, you can use the reset button to recreate the expression.
  • The result of the expression becomes the score for each round.
  • A total of 10 rounds are played, and in Maxi games, the side with the higher cumulative score wins!
  • A total of 10 rounds are played, and in Mini games, the side with the lower cumulative score wins!
  • Calculation skills improve while playing the game.
  • Numpple Cho uses only addition (+) and subtraction (-) operations and is easier than Numple. Suitable for students in Grade 2 or above who are comfortable with basic addition and subtraction.
  • Numpple Jam uses addition (+), subtraction (-), and multiplication (x) operations. Suitable for students in Grade 3 or above who have learned multiplication tables.
  • Numpple Mini uses addition (+), subtraction (-), multiplication (x), and division (÷). Suitable for students in Grade 4 or above. However, it's a game that requires critical thinking skills.
