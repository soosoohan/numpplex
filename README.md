# 넘플 X(Numpple X) 🎯 

**넘플 X는 넘즐의 규칙을 바꾸어 만든 새로운 게임입니다.**  
*A new spin-off of Numzzle with refreshed rules and gameplay.*

---

## 넘즐 시리즈 정리 

공통점: 사용자는 주어진 숫자카드와 연산기호 카드로 수식을 만듭니다.

### 📌 게임 종류 비교

| 수식 결과 방식       | 컴퓨터와 대결   | 사용자 2인 대결 |
|------------------|--------------|----------------|
| 🎯 목표값 맞추기     | 넘즐         | 넘플           |
| 🧮 최대값 만들기    | 넘즐 X 맥시    | 넘플 X 맥시    |
| 🧮 최소값 만들기    | 넘즐 X 미니    | 넘플 X 미니    |

---


### 🧩 연산기호 조합에 따른 시리즈 정리

| 사용 연산기호              | 넘즐 시리즈                   | 넘플 시리즈                    |
|------------------------|-----------------------------|-----------------------------|
| `+`, `-`               | 넘즐초, 넘즐초맥시, 넘즐초미니      | 넘플초, 넘플초맥시, 넘플초미니      |
| `+`, `-`, `×`          | 넘즐잼, 넘즐잼맥시, 넘즐잼미니      | 넘플잼, 넘플잼맥시, 넘플잼미니      |
| `+`, `-`, `×`, `÷`     | 넘즐, 넘즐맥시, 넘즐미니, 넘즐X    | 넘플, 넘플맥시, 넘플미니, 넘플X     |
| `+`, `-`, `×`, `÷`, `√`, `π` | **넘즐업** (아주 어려움)   | —                           |

※ "잼"은 중간 난이도, "업"은 고난도 확장판을 의미합니다.

---

### 🃏 카드 사용 규칙에 따른 분류

| 카드 사용 방식                 | 포함된 게임 종류                         |
|----------------------------|--------------------------------------|
| 모든 카드 사용                 | 넘즐 X, 넘플 X                         |
| 카드 일부만 사용 가능            | 넘즐, 넘플                             |
| 여러 장으로 여러자리 숫자만들기 금지 | 넘즐초, 넘플초, 넘즐 X, 넘플 X             |
